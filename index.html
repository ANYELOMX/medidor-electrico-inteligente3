¿Cómo conecto el Bluetooth?
  1. Enciende el ESP32 con el programa BLE del proyecto.
  2. Abre esta página en Chrome o Edge usando HTTPS o localhost.
  3. Pulsa Conectar ESP32.
  4. En la ventana del navegador selecciona Medidor-ESP32.
  5. Acepta la conexión. Las mediciones aparecerán automáticamente.

No necesitas emparejarlo desde la configuración de Windows/Android. La conexión se realiza desde el botón de esta página.
